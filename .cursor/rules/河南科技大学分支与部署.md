# 河南科技大学 · 分支与部署约束

本工作区（目录名含「河南科技大学」）**只对应 Git 分支 `河南科技大学`**，与仓库的 `main`（主版本）解耦。

## 必须遵守

- **默认开发分支**：`河南科技大学`。日常 `git push` 只推该分支。
- **Netlify 生产地址**：https://haustsmartteaching.netlify.app/  
  Netlify 后台「Branch to deploy」必须为 **`河南科技大学`**。
- **禁止**：在未得到用户**明确书面指令**前，合并到 `main`、向 `main` 推送、把 CI 触发改回 `main`，或扩大 `remote.origin.fetch` 去常驻跟踪 `main`。

## 例外

仅当用户明确说需要「合并到主版本 / 同步 main」时，再执行与 `main` 相关的 git 或配置变更。

## 配置文件锚点

- `.git/config`：`remote.origin.fetch` 仅 `河南科技大学`
- `.github/workflows/deploy-netlify.yml`、`deploy-github-pages.yml`：触发分支为 `河南科技大学`
- 根目录 `netlify.toml`：文首注释写明站点与分支绑定
